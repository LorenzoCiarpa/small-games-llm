## 3. Distance in weight space, layer by layer

Only between networks with the same shape. For each layer (weights and biases together) and for the whole network:

- **relative distance** ‖A − B‖ / √(‖A‖² + ‖B‖²): 0 = identical, 1 = uncorrelated (like two orthogonal vectors), √2 = opposite; the cosine says the same thing (1 = same direction, 0 = uncorrelated);
- **raw**: as written; **aligned**: after reordering (and, for tanh, sign-flipping) the hidden units of B in the way that brings it closest to A, which does not change the function of B;
- **null**: the same aligned distance, but with B replaced by B with its values shuffled at random within each layer (same values, same sparsity, no structure), mean over 20 shuffles. If *aligned* ≈ *null*, the two networks have no more in common than two random networks with the same values would have.

Caution: in the hand-written networks the norm is dominated by a few huge weights (up to 1000), so ‖A − B‖ of a layer or of the whole network mostly measures where those few weights are; for a saturated tanh, 100 and 1000 do almost the same thing. The cosine and sections 4–6 do not depend on the scale.

Alignment check: a network against a copy of itself with the units shuffled gives distance 0.0e+00 (must be 0).

## 7. Astra's networks for the four games, including different shapes

The three MinAtar networks are 600-32-32-6; the Low Tide one (`gpt/low_tide`) is 403-43-61-53-5, with one more hidden layer and the actions in a different order. To compare them, each network is rewritten, *without changing what it computes*, in a common space:

- inputs: 10×10 grid with 7 channels (the 6 of MinAtar plus Low Tide's water) and Low Tide's 3 scalars; in Low Tide agent → player, jellyfish → danger, shells → reward. A network has weight 0 on the inputs it does not have;
- actions: noop, left, up, right, down, fire (Low Tide has no fire: a row of zeros);
- hidden layers: widened with zero units when needed (a unit with no weights changes nothing).

Then:

- **first layer** and **output**: each layer is aligned on its own, reordering (and, for tanh, sign-flipping) the hidden units; it is the most favourable alignment possible for that layer, computed exactly;
- **intermediate layer, networks with the same number of hidden layers** (the three MinAtar ones and `claude/low_tide`): a single alignment for the whole network, as in section 3 (exact);
- **intermediate layer with `gpt/low_tide`**, which has two intermediate layers: each one against the one of the other network, reordering rows and columns together. This problem cannot be solved exactly: the cosine found is a lower bound, and next to it is the von Neumann **upper bound** (no reordering can exceed it). The most similar pair of layers is kept.

Cosine 1 = the same weights up to a scale factor, 0 = nothing in common; *null* = the same alignment with the values of B shuffled at random (mean ± std. dev. over 20). `claude/low_tide` is included as a reference: same game as `gpt/low_tide`, different author.

Checks: each network against a copy of itself with the units shuffled gives minimum cosine 1.000000 with the exact methods (must be 1); the approximate method recovers the shuffled intermediate layers of `gpt/low_tide` with minimum cosine 0.82.
